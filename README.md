One line, at most 200 characters, roasting a smart fridge. Entry for the
make.fun bounty "Fridge Roast: One Line, Biggest Laugh".

## Entry

`main.py` writes a single roast line to `/output/entry.txt`.

## Run

```sh
python3 main.py
```

Set `OUTPUT_DIR` to change the output directory (default `/output`).
